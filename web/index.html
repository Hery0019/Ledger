Ledger

An embedded SQL engine written in C++20, compiled to WebAssembly. Everything below runs inside this tab, on an in-memory database: no server, nothing sent, nothing stored. Source on GitHub.

  • C++20
  • WebAssembly
  • joins · aggregates · views
  • transactions
  • constraints & foreign keys
  • subqueries
Examples:
Loading the engine… Ctrl + Enter to run · statements end with ;

Each run is one session, like a request to the ledgerd HTTP server: statements run in order and stop at the first error, and a transaction must BEGIN and COMMIT within the same run. Tables stay between runs until you reset. Picking an example starts from an empty database.

Ledger is a learning project by Hery RAKOTONARIVO, released under the MIT license.
